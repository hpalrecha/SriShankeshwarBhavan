# WhatsApp Message Templates for Meta Approval

## Template 1: Pre Check-in Reminder
**Template Name:** `pre_checkin_reminder`
**Notification Type:** `pre_checkin_reminder`
**Trigger:** Daily at 10:00 AM for tomorrow's check-ins

### Message Template:
```
Hello {{1}}, 

Your check-in at Sri Shankeshwar Bengaluru Bhavan is tomorrow! 

Booking Details:
- Booking ID: {{2}}
- Check-in Date: {{3}}
- Room Type: {{4}}

Please arrive between 12:00 PM - 6:00 PM. Carry valid ID proof.

Contact: +91 9876543210

Looking forward to hosting you!
```

### Variables Sent:
1. `{{1}}` - Guest Name (user.name or booking.primaryGuestName)
2. `{{2}}` - Booking ID (booking.bookingId) 
3. `{{3}}` - Check-in Date (formatted as DD/MM/YYYY)
4. `{{4}}` - Room Category Name (category.name)

## Template 5: Login OTP

**Template Name:** `bhavan_login_otp`
**Notification Type:** `otp_verification`
**Trigger:** Every sign-in on the website - WhatsApp is the default OTP channel, email is the opt-out

### Message Template:
```
Sri Shankeshwar Bengaluru Bhavan

{{1}} is your one-time password to sign in to your booking account.

This code is valid for 5 minutes. Please do not share it with anyone.
```

### Variables Sent:
1. `{{1}}` - The 6-digit OTP (generated by `smsService.generateOTP()`)

### Category: UTILITY

This is deliberately **not** an Authentication-category template. Meta fixes the
body wording of Authentication templates ("{{1}} is your verification code."),
so the Bhavan's name cannot be put inside one - on that kind of template the only
name a guest sees is the WhatsApp Business display name, which is still the
borrowed "P91 India" number. A Utility template is the only shape whose body can
carry the Bhavan's name.

Two things follow from that, both of which matter:

- **Approval is not guaranteed.** Meta's stated policy is that authentication
  messages belong on Authentication templates, and a Utility template carrying a
  login code can be rejected on submission or flagged later. If it is rejected,
  the fallbacks are to submit it as an Authentication template (accepting Meta's
  fixed wording, no Bhavan name in the body) or to get the real business number's
  display name sorted out.
- **Turn OFF "Has a Copy code button"** on this mapping in Admin Panel → WhatsApp
  Settings → Templates. Utility templates have no Copy code button, and sending a
  BUTTON component to a template that lacks one gets the whole message rejected.
  Leave it ON only for an Authentication template.

### If submitted as an Authentication template instead

Name it `bhavan_login_otp_auth`, category **AUTHENTICATION**, with "Add security
recommendation" and a 5-minute expiry to match the server's OTP lifetime. Meta
supplies the body wording; there is no Bhavan name in it. Map it the same way but
leave **"Has a Copy code button" ON**.

## Template Configuration in Admin Panel

After Meta approves these templates, you need to:

1. Go to Admin Panel → WhatsApp Settings → Templates
2. Map each notification type to the approved template name:
   - `pre_checkin_reminder` → Your approved template name
   - `checkin_day_welcome` → Your approved template name  
   - `booking_cancellation` → Your approved template name
   - `post_checkout_feedback` → Your approved template name
   - `otp_verification` → Your approved template name (required - sign-in breaks without it)

## Meta Template Submission Guidelines

- Language: English (en)
- Category: UTILITY (for booking-related notifications)
- Variables: Use {{1}}, {{2}}, {{3}}, {{4}} format
- Keep content professional and informative
- Include clear business purpose (hotel booking notifications)
- Mention your business name: "Sri Shankeshwar Bengaluru Bhavan"

The system will automatically use these templates once approved and mapped in your admin panel.
